# BaseRoom

Copy room models here to replace the placeholder room:

- `room.glb` or `room.gltf`: the first room
- `room_<name>.glb` or `room_<name>.gltf`: more rooms, in alphabetical order

Press `R` in the game to cycle through them. Models should be in metres with the floor at y = 0.

See `docs/BASE_ROOM.md`. Files you add here are ignored by git (see `.gitignore` in this folder).
