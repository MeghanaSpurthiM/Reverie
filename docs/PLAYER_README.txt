REVERIE
=======

Reverie turns a text prompt into a themed VR play environment. This build plays one theme.
You don't need a headset. The game runs on a monitor with a keyboard and mouse.


GET STARTED
-----------

1. Unzip the whole folder.
2. Double-click Reverie.exe.

Requirements: 64-bit Windows and a graphics card that supports Direct3D 12. 3DGS scenes need a
recent dedicated GPU. The study used an NVIDIA RTX 5070 laptop.


KEYBOARD AND MOUSE
------------------

Left click              Front kick
A                       Side kick
D                       Wide kick
Arrow keys              Look around
Right mouse + move      Look around

1                       Audio on or off
2                       Skybox on or off
3                       3DGS scene on or off
4                       Tool and target on or off
5                       Base room on or off
R                       Next base room, when more than one is installed

Kick the falling targets with the paddles to score. The skybox, 3DGS scene and base room replace
each other, so only one shows at a time. The first load of the 3DGS scene takes a few seconds.

Alt+F4 quits the game on Windows.


META QUEST 3 (OPTIONAL)
-----------------------

1. Install the Meta Quest Link app on your PC and sign in.
2. In the app's settings, allow unknown sources and set Meta Quest Link as the active OpenXR
   runtime.
3. Connect the headset with a USB-C cable or Air Link, and start Quest Link in the headset.
4. Double-click Reverie.exe.

Right trigger           Front kick
B                       Side kick
A                       Wide kick
Left Y                  Show or hide the layer panel
Left laser and trigger  Use the layer panel


ABOUT THE BASE ROOM
-------------------

The base room in this build is a plain placeholder. The living room used in the study came from a
commercial asset pack that can't be redistributed.
